# Star Ratings

Create a simple star rating look with CSS

## UX

As a user, I want to view the number of stars.

## Features

Allows the user to see how many stars with the subject, user, date and comment (in quotes).

## Technologies

Uses HTML5, CSS3 and Font Awesome 7.0.1.

## Testing

To preview, use the command `python3 -m http.server` in the terminal.  Check that the page comes out as expected.

## Deployment

On [GitHub Pages](https://derektypist.github.io/star-ratings) at the main branch.
